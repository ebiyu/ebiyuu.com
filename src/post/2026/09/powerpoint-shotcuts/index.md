日本語キーボードを想定。

## 簡単で便利なので覚えておくべきショートカット

|      |              |
| ---- | ------------ |
| 下付き  | `Ctrl` + `;` |
| 上付き  | `Ctrl` + `Shift` + `;` |
| 数式挿入  | `Alt` + `;` |
| 文字サイズ小  | `Ctrl` + `[` |
| 文字サイズ大  | `Ctrl` + `]` |
| 文字左揃え  | `Ctrl` + `L` |
| 文字中央揃え  | `Ctrl` + `E` |
| 文字右揃え  | `Ctrl` + `R` |
| 文字両端揃え  | `Ctrl` + `J` |
| 太字  | `Ctrl` + `B` |
| 斜体  | `Ctrl` + `I` |
| 下線  | `Ctrl` + `U` |
| グループ化  | `Ctrl` + `G` |
| グループ解除  | `Ctrl` + `Shift` +/ `G` |
| スライドを挿入 | `Ctrl` + `M` |
| 新しいウィンドウ（同一ファイル） | `Ctrl` + `Shift` + `N` |

## Alt系

`Alt` を押すとガイドが出る。あとは順にアルファベットキーを押していくと操作ができる。

特に以下は、頻出なので覚えておくと便利。

整列 `Alt` → `H` → `G` → `A` → 

|                                  |     |
| -------------------------------- | --- |
| `L` | 左 |
| `C` | 左右中央 |
| `R` | 右 |
| `T` | 上 |
| `M` | 上下中央 |
| `B` | 下 |
| `H` | 左右等間隔 |
| `V` | 上下等間隔 |

並び順 `Alt` → `H` → `G` →

|                                  |     |
| -------------------------------- | --- |
| `K` | 最背面へ |
| `R` | 最前面へ |
